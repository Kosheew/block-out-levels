Block Out Level Lab

Доступ на редагування

Переглядати може будь-хто. Щоб зберігати версії, правки і завантажені файли, потрібен GitHub-токен з правом запису в Kosheew/block-out-levels. Кожне збереження — окремий коміт, тож історія змін не губиться.

  1. Власник репозиторію додає вас у Settings → Collaborators.
  2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → block-out-levels; Permissions → Repository → Contents: Read and write.
  4. Вставте токен нижче. Він зберігається лише в цьому браузері.
